# Cuestionario: Fuentes de información médica

Sitio interactivo con opción múltiple, verdadero/falso y ejercicios para identificar conceptos de e-learning, MeSH, búsqueda estratégica y revisión sistemática.

## Publicar en GitHub Pages
1. Sube `index.html` y `README.md` a la raíz de un repositorio.
2. Entra en **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**, rama `main` y carpeta `/(root)`.
4. Guarda y abre la URL que GitHub Pages te indique.

Nota: las respuestas se elaboraron a partir de las diapositivas proporcionadas; no se entregó una clave oficial.
